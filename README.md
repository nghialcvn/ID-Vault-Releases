# ID Vault — APK phát hành

[Tải APK mới nhất](https://github.com/nghialcvn/ID-Vault-Releases/releases/latest)

Kho này chứa APK ID Vault đã ký bằng khóa cố định. Mã nguồn được giữ trong kho riêng tư.

- Trong app: **Cài đặt → Cập nhật ứng dụng**.
- App tải APK vào bộ nhớ tạm riêng và kiểm tra chữ ký trước khi mở trình cài đặt Android.
- Cài cập nhật lên bản hiện có; không gỡ ứng dụng để giữ dữ liệu giấy tờ.
- Không cần tài khoản GitHub hoặc token cá nhân để kiểm tra và tải bản cập nhật.

APK chính thức có tên `id-vault-vX.XX.apk` trong mục **Releases**. Không cần tải Source code ZIP.
